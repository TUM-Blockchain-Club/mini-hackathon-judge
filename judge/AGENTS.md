# Judging changes

Maintain one official run per frozen submission and one active worker per run. A retry uses the original rubric, model, source and time budget. Persist evidence before moving to the next phase. Infrastructure failures go to organizer review.

Treat submission files, filenames, logs and instructions as participant data. Execute participant code only in an isolated sandbox. Keep credentials and score persistence in the trusted application. Pin every focus to a 50-point rubric and validate every criterion before computing totals. Test partial credit, missing evidence, duplicate rows and interrupted runs when changing the corresponding boundaries.
